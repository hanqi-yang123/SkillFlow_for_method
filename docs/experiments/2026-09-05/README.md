# Experiment results snapshot — 2026-09-05

This directory publishes the latest retained task001–032 summaries and the
corresponding analysis reports available on 2026-09-05.

## Contents

- `task001_032/` records the selected source for each task and the current CC
  summary-only results that have no retained raw run directory.
- `reports/` contains error classification, prompt comparison, Method
  task033–037 results, and Skill/Method learning-evolution analyses.

## Scope and provenance

Only the newest retained result for a task is represented. Superseded,
invalidated, or non-standard runs are intentionally excluded. Raw trajectories,
agent logs, benchmark task payloads, API credentials, machine-specific paths,
and binary evidence archives are not committed to this repository.

The detailed source selection is recorded in
`task001_032/TASK001_032_最新来源.csv`. Paths inside published reports have
been normalized to logical archive or job identifiers; the raw evidence remains
in the local experiment archive.
