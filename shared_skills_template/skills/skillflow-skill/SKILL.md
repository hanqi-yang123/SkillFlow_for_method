# SkillFlow Task Method

Read the complete task and inspect all relevant inputs before editing. Derive a
small execution plan from the requested deliverables and acceptance criteria.
Work in the assigned workspace, validate outputs from disk, and report only
checks that were actually run. If a check fails, diagnose the produced artifact,
fix it, and rerun the strongest available validation.
